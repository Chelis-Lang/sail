# HumanEval proof lost after stable spec-formal lowering

Status: release blocker [#337](https://github.com/Chelis-Lang/sail/issues/337).
Native macOS 27.0, EC2 mac-m4.metal, us-east-1c; Rust/Cargo 1.99.1. Stock
Verus `7d829946231d6413a398f6e4160cdfe951261dad` verifies the mutation; bare
fork `f8589ed4345f147d8fb43d8cb7992921944b91f0` and selected Sail reject
`exists_even_index` with `postcondition not satisfied`. Both use identical
Z3 bytes (`edae32f9e37ea4b5bb35310d72f0e352d0dc07626cac4e9e30bc1ea9a5bc8efb`).

The script copies a pinned public project into a new private directory,
changes the initial length branch of `exists_even_index` from zero to one,
and wraps its complete crate using exact registry vstd and the captured lock.
It runs the independent stock and bare-fork runtimes without Sail or its cache:

```sh
python3 corpus/repros/verus-spec-formal-context/reproduce.py \
  --stock "$SAIL_STOCK_RUNTIME" --fork "$SAIL_FORK_RUNTIME" \
  --work "$SAIL_REPRO_SCRATCH"
```

Stock exits zero; the affected fork exits 101. Exit two from the script keeps
this disagreement visible. Stdout, stderr, commands and literal SMT stay in
scratch. The full mutation suite reproduces it in each of three rounds; a
fresh single-mutant sequence and independent fresh Cargo arms reproduce it too.
Linux's full corresponding cohort matches stock.

Keeping the complete crate matters: reducing it to this one module makes
stock fail too, while a three-function extraction passes both runtimes. Those
reductions do not reproduce the original disagreement. The small runner
therefore fetches the original pinned source rather than checking in a large
or misleading standalone fixture.

Captured SMT replay identifies Z3's response as `unknown` with reason
`incomplete quantifiers`. The failing proof query itself is unchanged; the
fork's earlier spec termination checks use positional formal names. Restoring
that earlier termination context, or distinguishing formal names by complete
signature size, restores `unsat` in the captured proof query. Merely changing
the shared name prefix does not. These are offline diagnostic controls, not
query normalization in Sail or acceptance of a different verdict. Candidate fork `7d9d5410` passes the actual Mac compiler reproduction with
all 331 function statuses equal to stock, plus 13 VIR library tests and all
five existing spec-parameter regressions. Whole-corpus and selected-product
qualification remain pending; the current selected release still fails.
See [VI-0034](../../../docs/verus-issues/VI-0034-spec-formal-solver-context.md).
