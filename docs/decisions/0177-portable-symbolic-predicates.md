# 0177. Recheck portable predicates in a selected Dive installation

Accepted for the point-release follow-on to [native edit evidence](0176-native-temporal-edit-evidence.md).

A finite state predicate from another process can accelerate an edited safety
check even when the current transition relation has changed. The candidate
alone establishes neither the current verdict nor the reachable state count.

The local CLI accepts a trusted Dive executable and an explicit session
directory. Dive must bind the current source and prove all induction
obligations before Sail forwards an inductive proof. An inconclusive check
can spend the remaining wall budget on a complete search. Each verified
counterexample carries Dive's independent validation result. Sail bounds
the subprocess and report, checks the result class and current input paths,
and forwards the original JSON bytes to preserve integer precision.

Publication of a replacement candidate requires an admitted successful search
and a regular staged predicate file. Atomic rename gives concurrent receivers
a complete candidate. The symbolic command uses a separate result schema and
storage directory. The daemon and authenticated worker continue to implement
the ordinary native contract in [ADR 0175](0175-exact-temporal-receipts.md).
