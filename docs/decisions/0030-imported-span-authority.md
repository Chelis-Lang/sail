## Decision

Implement an **unselected, conservative Loaded-Foreign candidate**, not a change
to stock verification or the selected source variant. Capture bounded original
stable crate/range/expected raw hash authority during SpanContext construction,
only for the optional interactive preparation selector. Move the same owned
admission into pre-focus validation; never duplicate the seed or retain compiler
state across revisions. Revalidate current Loaded Foreign identity, exact stock
bounds, complete name/current typed hash/stable file identity/normalization and
namespace/range/content uniqueness. Unknown, changed, ambiguous, Delayed, None,
Busy and local fallback states miss. Ordinary source loading is untouched.

For a raw unit import with exact two-word original range, bind complete original
and selected semantic identity. Check current index/start/end as original→current
translation coordinates; do not use those session coordinates as cross-callback
equality fields. The current `(id,data,as_string)` binding and current raw Arc
remain mandatory, as do all local lo/hi/hygiene/parent negatives and every other
exact lowering/graph/effect input. Original metadata lacks a hash-kind tag: retain
its complete bytes and the actual current typed kind; do not infer an original
kind. No query or source-span text normalization is introduced.

Use explicit `sail-prepared/graph-ledger/loaded-foreign-authority/v5` keys.
Portable version3 remains because representation is unchanged. Intact old entries
cannot be re-labelled, re-sealed or reused. Add bounded read-only initial/pre-focus
state evidence so qualification records actual resolver authority for the measured
binding, including unsupported states without promoting them.

One8MiB process-wide mapping admission includes inline original authority, record
capacity, bounded names, Arc/control metadata and formatter/growth margin. Physical
record disposal precedes admission release. Late validation has no duplicate
allocation. The existing prospective492MiB phase maximum becomes500MiB with this
owner; this is not yet a qualified bound or RSS claim.

## Consequences

A Loaded imported source may relocate while exact current diagnostic authority
and semantic input remain bound. Delayed-descriptor reuse is explicitly excluded;
the candidate may safely miss the actual workload if its selected mapping is not
Loaded Foreign. Failure to acquire/validate the snapshot causes fresh lowering,
without changing default verdicts or claiming proof reuse.

Before selection, require actual library/strict checks, ordinary vstd verification,
old-domain rejection, all original source/negative/cancel/late-error controls and
600-second previous-revision focus gate. Cached/fresh raw wire, effects and grouped
diagnostics from one compiler input and independent stock verdict/diagnostics must
pass. State evidence, complete HE/Vest proof/performance and live-reader gates
remain required. Preserve the earlier strict progress failure and relocation miss;
API controls or static review cannot qualify the source runtime. Implementation,
budget detail and pending tests are in [the candidate guide](../validation/m7.md).
