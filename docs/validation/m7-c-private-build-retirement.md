# Closed compiler-script control target retirement

The private C native target is retired after two independent holder checks in
each of the acceptance and handoff containers. Live process birth, command, cwd,
FD target/inode and mapping metadata show no holders and no unreadable records.
The raw control archive and its embedded tested executable were independently
rehashed first. The tested script-control executable and prior guarded-output
profiler were moved outside the target and rehashed before and after deletion.
No common target, active actor, source runtime, source tree or B target changed.

The [file-allocation record](m7-c-private-build-retirement.json) accounts for
325,447,680 bytes initially, retains 56,774,656 bytes of runnable images and
retires 268,673,024 bytes of compiler-file allocation. Both containers confirm
the target is absent. These figures describe file allocation, not an attribution
of concurrent host free-space changes. All raw controls and original failures
remain available; this cleanup has no proof or performance acceptance scope.
