## Release procedure summary

Full procedure: `docs/releasing.md`. Worked example:
`docs/validation/release-candidate.md` (rc.7 and 0.1.0).

Tiers and approximate times on a native lane:

| Tier | Time |
|---|---|
| `ci/local.sh gate` | ~2.5 min |
| `ci/local.sh conformance fast pr` | ~1.5 min |
| `ci/local.sh conformance fast` | ~7.5 min |
| `ci/local.sh conformance standard` (includes Anvil) | ~75 min |
| `ci/local.sh conformance deep` | over 3 h, own lane |
| `ci/local.sh deep-rvt`, `deep-rvt cache`, `scripts/verus-determinism.py --runs 3` | own lane |
| perf, six rounds | Anvil ~2 h 45 min, others under 1 h |

One lane per job, c7i.8xlarge, with `SAIL_PERF_TTL_MIN` set so hosts expire.

Release steps:

1. PR setting the workspace version and moving `CHANGELOG.md` Unreleased
   entries under it; regenerate `THIRD-PARTY-NOTICES` if the fork, Z3 or
   locks changed.
2. Linux stage: `ci/local.sh release` on a native host.
3. macOS stage on a `scripts/perf-host-mac.sh` host.
4. `scripts/release.sh package VERSION dist/stage/linux dist/stage/macos`.
5. Create the **draft** release from those assets.
6. Run the `attest-release` workflow on the draft; `gh attestation verify`
   both archives.
7. `scripts/release-smoke.sh` on both archives.
8. Install walkthrough on both platforms (Linux under umask 002).
9. Publish (`gh release edit vVERSION --draft=false`). Agents publish; the
   owner delegated this.

## Environment traps

- **Stale local checkout.** The main clone's local branches are pre-scrub
  history. Work only in worktrees made from `origin/main` after `git fetch`.
  Never push an old local branch.
- **Sandbox ssh** fails with "Bad owner or permissions on
  /etc/ssh/ssh_config.d/...". Put wrapper scripts for `ssh`, `scp`, `rsync`
  and git's ssh that add `-F /dev/null` first on `PATH`.
- **`GIT_CONFIG_GLOBAL=/dev/null`** drops the credential helper. Use it per
  command only.
- **Worktree sync.** A worktree's `.git` is a pointer file, so
  `scripts/perf-host.sh sync` gives the host no history and the gate fails
  there. Give the host real history (a full clone, or push and fetch). Fix
  in progress: #589 / draft PR #596.
- **Hosts have no `gh` auth.** Pass `gh auth token` over ssh stdin or
  environment for the one step that needs it. Never write it to disk.
- **AWS:** the long-lived IAM user was deleted. Use the SSO profile
  `EmployeeAccess` (`aws sso login`). If SSO expires mid-run, stop and report.
- **Mac dedicated host** bills 24 h minimum and needs owner approval.
- **`scripts/perf-host.sh list` must be empty** at session end.
- **Daemons outlive caches.** Sockets live under `/tmp/sail-<hash>/`; stop
  the daemon before deleting a cache; deleting the cache alone leaves it
  running.
- **macOS `/tmp` is a symlink**, which makes the shipped vstd proof refuse
  (#601). Use `realpath` for `SAIL_CACHE_DIR` until #601 lands.
- **`RUSTUP_TOOLCHAIN=1.99.1`** on both perf arms, except Anvil.

## Rules agents break

- Never weaken a check, golden, test or benchmark baseline.
- No query normalization (charter rule 5).
- Fix nondeterminism in the fork (ADR 0039), never in Sail.
- No AI markers in commits, PRs or issues. Run `cargo xtask install-hooks`
  once per clone.
- Never `--admin`, never `--no-verify`. Squash-merge only after all six
  required checks pass (`gh pr merge N --squash --auto`,
  `gh pr checks N --watch --required`, `gh pr update-branch N`).
- Never measure performance under emulation or on a shared or loaded host.
- No account ids, bucket names, home paths or emails in public text.
- A refused benchmark sample counts as a failure, never as a dropped sample.
- A `MODE_NATIVE_SHA256` mismatch means a review of the native binding, not
  a hash bump (see #607).
