# Sail 0.1.0 release notes

Released 2026-10-29. This is the first release of Sail. It was qualified as
`0.1.0-rc.7` on Linux and macOS
([#282](https://github.com/Chelis-Lang/sail/issues/282),
[record](../validation/release-candidate.md)). The full change list is in the
[changelog](../../CHANGELOG.md).

## What Sail is

Sail makes the Verus edit-verify loop faster for developers and coding
agents. `sail verify` takes the same arguments as `cargo verus verify` and
prints the same output. Behind it, Sail caches Z3 answers, reuses a
preverified vstd, reuses proofs of unchanged targets and restores the earlier
proof when you undo an edit.

In default mode Sail gives the same per-function verdicts, diagnostics and
exit codes as stock Verus with its pinned Z3, with one accepted, bounded
exception: code that reads Sail's named integration settings can see them
([ADR 0088](../decisions/0088-compiler-visible-integration-settings.md)). If
any part of Sail fails, it falls back to the pinned Z3 and the answer stays
correct.

## Platforms and install

- Linux x86-64 (glibc 2.39 or later) and macOS on Apple silicon.
- Each archive contains `sail`, the solver shim `sail-z3` and Sail's
  [Verus fork](https://github.com/Chelis-Lang/verus) runtime `47fb3be6`
  (upstream Verus `0.2026.10.18.7d82994`, Z3 4.16.0, proof-repair engine).
  No separate Verus install is needed.
- Proof reuse needs Cargo 1.93.0 to 1.99.1
  ([ADR 0084](../decisions/0084-qualified-cargo-range.md)). Other Cargo
  versions verify correctly with solver caching but without proof reuse
  (`SAIL3139`).
- Install with `scripts/install.py --version 0.1.0 --install-toolchain`. It
  checks the archive checksum and the bundled runtime, and verifies the
  build-provenance attestation when GitHub CLI is signed in. See
  [install](../install.md).

## Performance

Measured on the rc.7 archives against stock `cargo verus verify`, six paired
rounds per project on Vest, IronKV, CapybaraKV and Anvil, native Linux and
macOS. Full tables and method are in [performance](../performance.md).

- One-line edits are 1.2–2.5x faster than stock on every project and both
  platforms. Failing edits and fixes are faster too, from 1.07x on IronKV to
  about 6x on Anvil.
- Undoing an edit restores the earlier proof: up to about 34x faster (a Vest
  revert takes 1.1 s against 39 s on Linux).
- Unchanged calls after the first replay in 0.03–0.09 s, 3–9x faster than
  stock.
- Cold runs are at parity or faster; IronKV is 2.2x faster on Linux and 1.6x
  on macOS.

## Fixed during qualification

- Proof reuse now keeps the effective compiler-environment bindings (#551).
- Unchanged-call replay binds every environment variable the reused proofs
  read, including ghost-only reads (#552), terminal-capability variables
  (#573), and no longer repeats transient Cargo stderr such as lock waits
  (#574).
- A forced run of a non-default profile reverifies instead of failing (#553).
- The macOS runtime path scan no longer misses matches after `SIGPIPE`
  (#555).
- `install.py` applies the archive's directory modes regardless of umask, so
  the shipped vstd proof is used under umask `002` (#591).

## Known issues

The full list is in [known issues](../known-issues.md).

- The first unchanged call after a verification is slower than stock: it
  takes the full path and records the replay (Anvil about 2.4 s against
  0.36 s on Linux) (#558).
- Unchanged calls that do not replay, including `SAIL_MANAGED_NOOP=0` and
  forced jobs, pay the same setup cost (#560, #561).
- macOS Anvil cold is about 1% slower than stock (100.3 s against 99.4 s)
  (#232).
- On macOS, Vest reverts occasionally miss the restore fast path and take
  about 12 s instead of 1.1 s, still faster than stock (#595).
- Editing one function re-solves its module's whole solver session (#158).
- The shipped vstd proof is not used with `rustc-dev` or `llvm-tools`
  (#264), or with forwarded Verus flags other than a supported `--rlimit`.
- Some setups verify without proof reuse (`SAIL3112`): tests, benches and
  examples, `--target-dir`, loader variables and others listed in
  [workspace verification](../workspace-verification.md).
- Only Sail's own Verus release is supported, and single-file `verus file.rs`
  projects are not (#164).
